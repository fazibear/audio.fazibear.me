FAQ

A little help getting started.

Why can’t I type inside the plugin?

Configure your DAW to pass keyboard input to the plugin. In Reaper, click the + button at the top of the FX window and select “Send all keyboard input to plug-in”.

Why doesn’t Namplifier appear in my DAW on Windows?

Try installing the Microsoft Visual C++ Redistributable, then rescan your plugins.

What dependencies does the Linux version need?

The Linux build is the least-tested version. The original build uses Ubuntu with the following dependencies:

sudo apt install libwayland-dev libx11-xcb-dev libxcb-dri2-0-dev libgl1-mesa-dev libxcb-icccm4-dev libxcursor-dev libxcb-{render,shape,xfixes}0-dev libasound2-dev libgl-dev libjack-dev libxcb1-dev libxkbcommon-dev libfontconfig1-dev
